# Summarize and Pin: Carrying Context Forward

---

Here's the technique that separates people whose AI sessions feel effortless from people whose sessions feel like babysitting: **they control what goes into each fresh chat — on purpose, in writing, at the top.**

Call it a **context header** — a small block of text pasted as your first message that says: *who I am, what I'm working on, the decisions we've made, the rules to follow.* Then everything after that sits on a clean whiteboard with everything important already written on it.

## Why paste a summary instead of "just talking"?

Three reasons:

1. **Position matters.** Content near the top of a context window and content near the end both get strong attention; content buried in the middle gets the least. Your critical facts at the top of the chat sit in prime attention territory.
2. **You control what's kept.** Automatic memory and compaction (Chapter 3) choose for you. A hand-built header keeps exactly *your* priorities.
3. **It resets every time.** Any chat that starts with a context header starts ahead — fewer misunderstandings, fewer re-explanations, less drift.

## The 6-part context header template

Copy this. Fill the bold parts. Delete what doesn't apply. Save it in your notes app so you can paste it any time.

```
CONTEXT HEADER

1. WHO I AM: [your role — e.g., "small-business owner, eBay reseller, health worker by day"]

2. WHAT I'M WORKING ON: [the current project, in 1-2 sentences]

3. DECISIONS ALREADY MADE: [bullets — e.g., "site name is fixed," "budget is $200," "we chose plain English over jargon"]

4. RULES TO FOLLOW: [how you want answers — e.g., "plain English," "keep replies under 300 words," "no jargon without defining it," "bullet points over walls of text"]

5. WHAT I DON'T WANT: [e.g., "don't re-explain basics," "no melodrama," "don't suggest tools I've already rejected"]

6. OPEN QUESTIONS: [what's still unresolved — this tells the AI where to focus]
```

That's 150-250 words. Tiny cost, huge return — it lives in prime attention for the entire chat.

## What goes in a summary — and what doesn't

In the header:

- **Concrete decisions** ("we chose option B"), not the debate about it
- **Standing rules** you want applied to every answer
- **Names of things** — tools, projects, people, deadlines — because names are the first victim of drift

Not in the header:

- History ("then on Tuesday we tried X but it failed" — only matters if the lesson changed a decision)
- The full text of every document — paste docs per Chapter 6, only when the chat needs them
- Everything. If *everything* is important, *nothing* is. Let the header be the shortlist.

## Pinning, saving, and the tool-side versions

Different tools give you ways to make things *stickier* than an ordinary first message:

- **Pin/star a message** — some tools let you bookmark a message so it stays prominent. Use it for your context header and for mid-task pivots ("we're switching to plan B now").
- **Custom instructions / system prompts** — a standing "ABOUT YOU" block the tool appends to *every* chat beyond the whiteboard. Put your identity-level prefs there — tone, role, structure. Project-specific stuff does NOT belong there (it pollutes every unrelated chat). Chapter 8's tour shows where.
- **Saved memories** — the tool remembers atomic facts across chats ("user is a nurse," "user hates emoji"). Great for durable facts, mediocre for project context, occasionally wrong in amusing ways — inspect it occasionally.
- **Timeless rule:** whatever the tool auto-remembers, you can usually view and edit it — and *you* should. Auto-memory works best when it records facts you'd have written anyway.

## The "re-anchor" move

Mid-task drift happens even in good chats. When it does, don't argue with the AI — re-anchor:

> **"Quick reset. Re-read my context header. We're working on [TOPIC]. Confirm what you think the current focus is, then continue from there."**

That's it. No scolding, no re-explaining from memory. The header — still sitting there at the top of the chat — does the work, and asking for a confirmation-of-focus make the AI re-read it.

## Try this

1. Fill out the 6-part template for your current busiest project, right now, for real. Save it.
2. Open a fresh chat, paste it, and give the chat a real task. Compare the answer's *relevance* (not cleverness) to what your usual chats produce.
3. If your tool lets you pin or star messages: pin the header in your next working chat so it's always one scroll away.
4. Check whether your tool has **custom instructions** — and be honest: does what's there match how you actually like answers? Fix it today. (Tour in Chapter 8.)
