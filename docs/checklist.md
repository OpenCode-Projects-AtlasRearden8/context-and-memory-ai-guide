# The Context & Memory Checklist

---

No theory here — just the moves, ordered by situation. Print it, pin it, or live in it.

## Starting any new chat

- [ ] New purpose? Then a new chat. (One chat, one purpose.)
- [ ] Paste your **context header** first (the 6-part template from Chapter 5).
- [ ] State the actual task in this chat's own words — not "continue where we left off."
- [ ] Working past a document? Paste only the relevant section **with an on-ramp message** ("below are the payment terms; focus ONLY on …").

## While the chat is working

- [ ] Set rules *early* — formatting, tone, length. They most easily drift away from set-late instructions.
- [ ] Roughly every 10-15 exchanges: "recap what we've agreed on so far" — read it, correct it if wrong.
- [ ] New topic? New chat (old chat = archive).
- [ ] Mid-chat pivot ("okay, we're changing direction to plan B")? Say it *explicitly* and re-anchor.
- [ ] Instructions the AI breaks repeatedly? Restate the rule *in the same message* as the task — fresh wording gets fresh attention.

## Ending any chat that mattered

- [ ] Closing ritual: "Before we finish: compact handoff note — project, decisions, open questions, constraints. Bullets, under 250 words."
- [ ] Read the note. Fix it if the important thing got left out.
- [ ] Save the note where you keep project notes (not in browser-tab limbo).

## Whenever drift hits (this chat feels off)

1. [ ] **Re-anchor:** "Re-read my context header. Focus is [X]. Confirm, then continue."
2. [ ] Or restate the rule beside the current request.
3. [ ] Or get and correct a recap — paste it back as "use THIS as our reference."
4. [ ] Or start fresh with the handoff note. (Honestly, often the fastest.)

## Monthly maintenance (10 minutes)

- [ ] Read your main tool's **saved memory list**. Delete stale/wrong/embarrassing items.
- [ ] Re-read your **custom instructions**. Fix anything past-me wrote wrong.
- [ ] Check **data controls**: training opt-out if you want it, retention setting you can live with.
- [ ] Close or archive dead chats. Your workspace is part of your context life.

## Whenever privacy matters

- [ ] Strip personal identifiers before pasting (Chapter 6 discipline).
- [ ] Sensitive docs → AI explains *structure and terms*, not your private data.
- [ ] Handling anything truly private → use a temporary/memory-free chat if the tool offers one, and paste only what's needed.

## When in doubt, the whole manual in one line

**Fresh whiteboard, pasted summary, stated rules, occasional checkpoints, deliberate endings.**
