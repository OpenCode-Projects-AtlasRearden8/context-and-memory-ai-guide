Context & Memory the AI guide nobody passed to you

Reading guide · Glossary

Glossary

Every term this manual uses, in plain English, alphabetized. Skim it; keep it.

Attention (the AI's) How the model decides which parts of its context matter for the next word it's writing. Not equal across the whiteboard — strongest at the top and bottom, weakest in the middle. The physics behind both "position matters" (Chapter 5) and drift (Chapter 7).

Auto-compaction When a tool automatically compresses old messages in a long chat into a summary so newer content fits. Better than silent smudging, but the tool — not you — chooses what survives. See Compaction roulette in Chapter 7.

Checkpoint A mid-chat pause where you ask the AI to recap what's been agreed on, which you then correct. The cheapest drift-prevention there is.

Context header Your 6-part opening message in a fresh chat: who you are, project, decisions, rules, exclusions, open questions. The single highest-leverage habit in this manual. Template in Chapter 5.

Context window The AI's working memory for one chat — the "whiteboard." Everything said, generated, or pasted in that chat competes for this space. Measured in tokens.

Cross-chat memory Tool features that carry facts (not full transcripts) between chats: saved memories, custom instructions, project knowledge. Per-tool details in Chapter 8.

Custom instructions A standing "about me and how to answer" block applied to every chat, across projects. For identity-level preferences, never project specifics.

Data controls The settings area where you choose whether chats train future models and how long history is retained. Find it once, then relax.

Drift The gradual slide of a long chat — rules fading, answers going generic, topics blending. Predictable; preventable. Chapter 7.

Fresh chat A new, empty working memory. Not "losing your work" — a reset for attention quality, with your hand-carried summary bringing forward only what matters. Chapter 4.

Handoff note The compact "project, decisions, open questions, constraints" summary captured at the end of a good chat, carried by you into the next one. Chapter 4's closing ritual.

Local AI AI models that run entirely on your own computer (Ollama, LM Studio, and friends). Maximum privacy; usually no cross-chat memory at all — which makes your manual context skills the whole game.

Memory (saved) Atomic facts a tool stores about you across chats ("user is a nurse"). Inspect and prune monthly; it sometimes "remembers" surprising things.

Mega-thread One chat doing the job of five. Rarely the best of all worlds; usually attention dilution. Diagnose with the worksheet Part 1.

Model The specific AI you're talking to. Different models have different context window sizes, different tokenizers, different memory features — same concepts.

On-ramp message The instruction that accompanies a pasted document, saying what it is and what you want done with it. Turning pastes from noise into pointed attention. Chapter 6.

Personalization settings The settings area holding saved memories, custom instructions, profile controls. The Chapter 8 tour ground.

Pinning Marking a message to keep it prominent (in tools that allow it). Use for context headers and pivot moments.

Position An idea from Chapter 5: content near the start and end of the context window gets strong attention; content in the middle gets less. Place important stuff at the top.

Prompt engineering The older, narrower cousin of what this manual teaches: crafting good instructions. Necessary — but context and memory management is what makes every single prompt better.

Recap Asking the AI to summarize where you are mid-chat ("recap what we've agreed"). Reveals smudges; creates a correctable reference point.

Re-anchor Mid-drift rescue: point the AI back at its context header and current focus, and get confirmation before continuing. Chapter 7's step 1.

Retention How long chat history is kept (settings exist; auto-delete is offered). Set deliberately — deleting work archives stings more than a privacy slider feels good.

Saving memory What happens when you (or the tool) tell it "remember that…" — the fact goes on the cross-chat memory list rather than living only in this chat.

Smudging The informal word for what happens to old messages as a context window fills — not deleted, but weighted so lightly the AI effectively loses them.

Temporary chat / memory-free chat Some tools offer chats that skip saved memories and (often) history. Useful for anything you'd rather not touch your account. Chapter 8.

Token The chunk of text AI actually reads — roughly ¾ of a word, but varies by text. Words are cheap-ish; weird characters and whole documents are expensive. Chapter 1.

Whiteboard (the) This manual's mental model for the context window: clean at the start of a chat, fillable, and smudging at the edges when full. If you remember one image, remember this one.
